# Images folder

Upload photos here and name each file exactly as below. `.jpg` is recommended, about 1600 px wide and under 500 KB.
Each photo shows up in the listed places after the next deploy. A name with no photo uploaded stays hidden.

## More than one photo for the same thing

Every name below can have extra photos. Add `-2`, `-3` and so on before the extension:

```
gallery-events-iit-bombay.jpg
gallery-events-iit-bombay-2.jpg
gallery-events-iit-bombay-3.jpg
```

They appear side by side in the Images gallery with the same title, in number order.
You can also upload only `-2` without the first one.

## Photos that are not in this list

Upload them as `gallery-<category>-<short-name>.jpg`, where category is one of
`awards`, `leadership`, `research`, `training`, `events`, `projects`, `volunteering`.
Example: `gallery-events-tech-fest-2027.jpg` shows under Events titled "Tech Fest 2027".
For a nicer title, add a line for it in `GALLERY_PHOTOS` in `src/config/media.ts`.
