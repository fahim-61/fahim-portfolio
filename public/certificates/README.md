# Certificates folder

Upload certificate scans here. Name each file exactly as below (any of `.jpg` `.png` `.webp` `.pdf`; JPG or PNG recommended).
The entry's "View Certificate" button then shows the file, and it also appears in the Certificates gallery, after the next deploy.

Full guide, including how to add new ones: [README.md](../../README.md#2-certificates)
